## Small descriptions :

### python folder

#### kakuro_helper.py

You enter the number of boxes you have and then the sum of those numbers, and you'll have the suggestions; it helps for both kakuro and killer sudoku

Remarks : This is version 2 using recurrence, as my data got corrupted, and I lost version 1, which used a pure for loop that I forgot how I wrote at the time.

#### worldle_helper.py

You enter the number of letters; it starts by giving you suggestions with the most popular characters, and from there it uses regex to eliminate choices. If you choose strategically well from the suggested words, most of the time you won't exceed the third guess.
