#### kakuro_helper.py

You enter the number of boxes you have and then the sum of those number and you'll have the suggestions, it helps for both kakuro and killer sudoku

Remarks : this is version 2 using recurrence as my data corrupted and I lost version 1 which used purely for loop that I forgot how I wrote at the time

#### worldle_helper

You enter the number of letters, it statrt by giving you suggestions with the most popular characters and from there it uses regex to eliminate choices, if you choose strategically well from the suggested words, most of the time you won't exceed third guess
